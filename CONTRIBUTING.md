Obrigado por querer contribuir com o Goniômetro Digital Didático!

Antes de abrir issues ou pull requests, por favor leia estas orientações:

- Issues
  - Use o modelo apropriado (bug ou feature request) ao abrir uma issue.
  - Inclua passos para reproduzir, hardware usado, versão do Arduino IDE/arduino-cli e logs relevantes.

- Pull Requests
  - Baseie seu PR na branch `main` ou crie uma branch com nome descritivo (ex.: feat/ajuste-calibracao).
  - Explique claramente a mudança e por que é necessária.
  - Mantenha commits pequenos e com mensagens descritivas.
  - Inclua testes ou instruções de verificação quando aplicável.

- Estilo de código
  - Siga convenções simples de indentação (2 ou 4 espaços) e comentários em português claro.

- Responsabilidades
  - Este repositório é mantido por v-cap em nome do GEB. Alterações significativas podem ser discutidas antes de serem mescladas.

Obrigado!
