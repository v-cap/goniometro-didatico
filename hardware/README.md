Hardware e conexões

Este diretório contém informações sobre o cabeamento e notas de montagem do goniômetro.

Conexões (Arduino Uno -> MPU-6050):

- GND -> GND
- VCC -> 5V (ou 3.3V dependendo do módulo)
- SDA -> A4
- SCL -> A5

Observações:
- Alguns módulos operam em 3.3V; verifique o seu módulo antes de ligar direto em 5V.
- Utilize cabos curtos para reduzir ruído em leituras I2C.
